# Calendar Quick-Add

Paste an assignment notice and instantly extract the deadline, course code, and time. Add the event directly to Google Calendar, copy a shareable link, or download an .ics file for Outlook, Apple Calendar, or any other app. Includes a smart 1-day-before reminder—no extra steps needed.

## Features

- 🔗 One-click Google Calendar add via quick-add link
- 📱 Works offline as a PWA (installable app)
- 📅 Exports to `.ics` for Outlook, Apple Calendar, etc.
- 🎯 Smart text parsing (dates, times, course codes)
- 🔔 Optional 1-day reminder event
- 🌙 Dark mode support

## How to Use

### Option 1: Add Directly to Google Calendar (Easiest)
1. Paste your assignment text or fill in fields manually
2. Click **"Add to Google Calendar"** → Opens Google Calendar quick-add
3. Review & click "Save" → Event added instantly

### Option 2: Copy & Share the Link
1. Fill in the assignment details
2. Click **"Copy link"** 
3. Paste the URL anywhere — when you click it, Google Calendar opens to add the event

### Option 3: Download for Other Calendar Apps
1. Fill in the assignment details
2. Expand **"Use with Outlook, Apple Calendar or another app (.ics)"**
3. Click **"Download .ics"** (or copy the text)
4. Open the file with your calendar app — it adds the event + built-in reminder

## Quick Start

1. Visit the [live app](https://assignmentdue.netlify.app) (or self-host)
2. Paste assignment text or fill in the form
3. Choose your workflow above → Done

**Install as an app:** On desktop, browser offers install prompt. On iOS: Share → Add to Home Screen.
